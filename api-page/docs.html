Dokumentasi API

Andri API V1.0 — Platform API berbasis Node.js + SQLite dengan autentikasi session, rate limiting per plan, dan pembayaran otomatis via Pakasir.

Autentikasi API Key
Cara mengautentikasi request ke API

Setiap request ke endpoint API harus menyertakan API key dengan format Apikey+ diikuti 48 karakter costum. Generate key dari halaman Profile.

Query Parameter

GET /api/ai/luminai?text=Halo&apikey="YOUR APIKEY"

Request Header

{"x-api-key": "You Apikey"}
Format Response
Struktur standar response API

200 OK — Sukses

{
  "status": true,
  "statusCode": 200,
  "creator": "Andri Store",
  "result": "...",
  "status": "true"
}

404 Not Found

{
  "status": false,
  "statusCode": 404,
  "message": "Endpoint tidak ditemukan.",
  "error": "ENDPOINT_NOT_FOUND",
  "status": "false"
}

500 Server Error

{
  "status": false,
  "statusCode": 500,
  "message": "Internal server error.",
  "error": "SERVER_ERROR"
}

429 Rate Limit Exceeded

{
  "status": false,
  "statusCode": 429,
  "error": "RATE_LIMIT_DAY",
  "limit": 100,
  "used": 100,
  "plan": "free",
  "result": "habis"
}
Rate Limiting
Batas penggunaan per plan

Setiap endpoint API dibatasi berdasarkan plan yang aktif pada API key. Limit dihitung per menit, per jam, dan per hari. Jika salah satu batas terlampaui, request akan ditolak dengan response 429.

Header response berisi informasi penggunaan saat ini:

X-RateLimit-Limit: 100
X-RateLimit-Remaining: 42
X-RateLimit-Reset: 1718000000

API Endpoints
Daftar lengkap endpoint yang tersedia

POST /api/auth/register

Daftar akun baru. Tidak perlu API key.

POST /api/auth/register
Content-Type: application/json

{
  "name": "Nama Kamu",
  "email": "kamu@email.com",
  "password": "password123"
}

POST /api/auth/login

POST /api/auth/login
Content-Type: application/json

{ "email": "...", "password": "..." }

POST /api/auth/logout

POST /api/auth/logout  // Menghapus session dari DB

GET /api/auth/me

GET /api/auth/me  // Perlu login (session cookie)

GET /api/ai/luminai

AI chat via Luminai. Memerlukan API key.

ParameterTipeWajibDeskripsi
textstringYaPertanyaan atau teks input
apikeystringYa"YOU APIKEY"
GET /api/ai/luminai?text=Halo apa kabar&apikey="YOU APIKEY"

GET /api/search/youtube

Cari video YouTube. Memerlukan API key.

ParameterTipeWajibDeskripsi
qstringYaQuery pencarian
apikeystringYa"YOU APIKEY"
GET /api/search/youtube?q=lofi music&apikey="YOU APIKEY"

POST /api/payment/create

Buat transaksi upgrade plan via payment otomatis. Perlu login.

POST /api/payment/create
Content-Type: application/json

{ "plan": "premium", "payment_method": "qris" }
// payment_method: all | qris | bni_va | bri_va | cimb_niaga_va | ...

POST /api/payment/webhook

Endpoint webhook dari Pakasir. Daftarkan URL ini di dashboard Pakasir: {APP_URL}/api/payment/webhook. Plan akan langsung aktif otomatis.
